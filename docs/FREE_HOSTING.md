# Free server hosting (Remom)

Remom does **not** run a full Java server inside the phone (that is a separate heavy product).

Instead, **Server Hub** opens free cloud hosts and you join with the same Play path.

## Flow

1. Open **Servers** (profile → Servers / Server Hub)
2. Tap **Aternos** or **Minehut** (browser)
3. Create server, start it, copy the address
4. Back in Remom → **Add** IP → **Play**

## Free hosts (honest limits)

| Host | Notes |
|------|--------|
| [Aternos](https://aternos.org/) | Free forever; queue at peak; sleeps when empty; good modpacks |
| [Minehut](https://minehut.com/) | Free tier ~1GB / 10 players; sleeps when empty; plugins |

Premium online-mode servers still need a Microsoft account that owns Java.
Offline / `online-mode=false` servers work with offline accounts.

## Not included

- Phone-as-dedicated-server (Anvil-MC style) — separate app/engine
- Paid VPS automation
